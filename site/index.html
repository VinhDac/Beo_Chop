main.py — written for you
"""Algorithm generated by Cat_Studio — RSI sample.
DO NOT EDIT BY HAND: reopen the diagram and generate again."""
from AlgorithmImports import *
 
class RSISample(QCAlgorithm):
 
    def initialize(self):
        self.set_start_date(2012, 1, 1)
        self.set_end_date(2014, 12, 31)
        self.set_cash(100000.0)
        self.set_brokerage_model(BrokerageName.DEFAULT)
 
        self._ten = {}
        self._ten['XAUUSD'] = self.add_cfd(
            'XAUUSD', Resolution.DAILY).symbol
        self._ma = list(self._ten.values())
        self.set_benchmark('XAUUSD')
 
        self._cb = {}
        for sym in self._ma:
            self._cb[sym] = {}
            self._cb[sym]['rsi_14'] = self.rsi(sym, 14)
 
        self.set_warm_up(14)
 
    def on_data(self, data):
        if self.is_warming_up:
            return
        for sym in self._ma:
            self._mot_ma(sym, data)
 
    def _mot_ma(self, sym, data):
        if (self._cb[sym]['rsi_14'].current.value
                < 30):  # 1A · Oversold?
            # 1A.1 · Go all in
            self.set_holdings(self._ten['XAUUSD'], 1, False,
                              tag='[1A.1] RSI(14) < 30')
        elif (self._cb[sym]['rsi_14'].current.value
                  > 70):  # 1B · Overbought?
            # 1B.1 · Exit everything
            self.liquidate(self._ten['XAUUSD'],
                           tag='[1B.1] RSI(14) > 70')

And it will not let you lie to yourself

Minus 9.87% — and that is a win.

Over those three years gold fell. Buying and holding it lost a quarter of the money. The engine above lost 9.87%, because it spent most of those years out of the market. Your result is always set beside buying and holding over the same dates, so a number can never flatter you on its own.

The boss is the obvious thing

Buy on the first bar, hold to the last. LEAN computes both curves. Beating it is the second of three stars.

The third star is a period you never saw

The same engine, re-run over dates the level never showed you. Tune it to fit the past and this is where you lose it.

No number is ours

Fills, sizing, margin, fees and slippage are LEAN's. Cat Studio computes nothing about the market — it draws, it checks, it translates.

What you keep

The diagram is a way in, not a lock-in.

What comes out is an ordinary QuantConnect algorithm. Take main.py to quantconnect.com, to your own LEAN, to any editor — and keep going without Cat Studio the day you no longer need it.

Runs on

  • Every quantity names its LEAN line. A block cannot exist unless it points at a real QuantConnect API — the library shows the line beside each of the 164 quantities.
  • Every order carries its block. The tag on a fill says which block fired it and on what condition, so LEAN's own log reads back onto the diagram.
  • It runs on your machine. A LEAN build you point it at. No account, no server, nothing uploaded, no LLM anywhere in it.
  • 26 levels teach the engine, not the app. Indicators, universes, pending orders, memory, fees — QuantConnect's own vocabulary, one idea at a time.
Get it

Install it, then point it at LEAN.

One installer, 13.7 MB, no admin rights: it goes into your own user folder. What it does not carry is LEAN itself — the reason is below, and it is not a small one.

  1. Download and run Cat_Studio-0.2-windows-x64-setup.exe

    Installs to %LOCALAPPDATA%\Programs\Cat Studio, adds a Start menu entry, and registers an uninstaller. Windows 10 or 11, 64-bit. There is a portable .zip too if you would rather not install anything.

  2. Build LEAN, or point at one you have

    LEAN is QuantConnect's open-source engine. Open Settings in the app and give it the folder that holds Launcher\ and Data\ — or drop a folder named Lean\ beside the app and it finds it by itself.

  3. Draw, then press Backtest

    Cat Studio generates main.py, hands it to LEAN, and shows you what LEAN sent back. Without LEAN you can still draw and still generate the algorithm — only the Backtest button will say it has nowhere to send it.

Your diagrams, drafts and scores live in du_lieu\ beside the app. Uninstalling does not touch that folder.

Why doesn't the installer include LEAN?

Three reasons, and none of them is size. The LEAN build is framework-dependent, so it needs .NET 10 already on the machine — shipping it means rebuilding LEAN self-contained, about 70 MB more. LEAN runs Python algorithms through pythonnet, so a Python runtime has to travel with it as well. And LEAN's Data/ folder carries no licence file: the engine is Apache-2.0, which does not automatically cover market data, so QuantConnect has to be asked before anything ships with it.

Size would have been the easy part: the engine is 115 MB, and a level needs only the daily bars of its own symbols — 320 KB for three of them.

Until that is settled, the honest arrangement is this one: you bring LEAN, and Cat Studio never pretends to be the thing doing the computing.

Does it place real trades?

No. Backtests on historical data. The Live button exists because LEAN has one, and it is switched off.

Do all 26 levels work?

Twenty-three. Levels 17, 18 and 19 ask about the company behind a symbol — P/E, market cap, self-filtering universes — which needs QuantConnect's fine data, a paid feed. Those three say so on their own card rather than failing quietly.

Which computers?

Windows 10 and 11. The app is Python with a web UI in a native window.

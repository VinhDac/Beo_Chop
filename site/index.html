main.py — written for you
"""Algorithm generated by Cat_Studio — RSI sample.
DO NOT EDIT BY HAND: reopen the diagram and generate again."""
from AlgorithmImports import *
 
class RSISample(QCAlgorithm):
 
    def initialize(self):
        self.set_start_date(2012, 1, 1)
        self.set_end_date(2014, 12, 31)
        self.set_cash(100000.0)
        self.set_brokerage_model(BrokerageName.DEFAULT)
 
        self._ten = {}
        self._ten['XAUUSD'] = self.add_cfd(
            'XAUUSD', Resolution.DAILY).symbol
        self._ma = list(self._ten.values())
        self.set_benchmark('XAUUSD')
 
        self._cb = {}
        for sym in self._ma:
            self._cb[sym] = {}
            self._cb[sym]['rsi_14'] = self.rsi(sym, 14)
 
        self.set_warm_up(14)
 
    def on_data(self, data):
        if self.is_warming_up:
            return
        for sym in self._ma:
            self._mot_ma(sym, data)
 
    def _mot_ma(self, sym, data):
        if (self._cb[sym]['rsi_14'].current.value
                < 30):  # 1A · Oversold?
            # 1A.1 · Go all in
            self.set_holdings(self._ten['XAUUSD'], 1, False,
                              tag='[1A.1] RSI(14) < 30')
        elif (self._cb[sym]['rsi_14'].current.value
                  > 70):  # 1B · Overbought?
            # 1B.1 · Exit everything
            self.liquidate(self._ten['XAUUSD'],
                           tag='[1B.1] RSI(14) > 70')

Get it

Install it, then point it at LEAN.

One installer, 13.7 MB, no admin rights. It does not carry LEAN — the reason is below.

  1. Download Cat_Studio-0.2-windows-x64-setup.exe

    Windows 10 or 11, 64-bit. No admin rights: it installs under your own user folder.

  2. Build LEAN, or point at one you have

    Settings → the folder holding Launcher\ and Data\. Or drop a Lean\ folder beside the app and it finds it.

  3. Draw, then press Backtest

    It writes main.py, hands it to LEAN, and shows you what came back.

Your diagrams, drafts and scores live in du_lieu\ beside the app. Uninstalling leaves them alone.

Why doesn't the installer include LEAN?

Not size. It needs .NET 10 present; it runs Python through pythonnet, so a Python runtime must travel with it; and LEAN's Data/ carries no licence file — Apache-2.0 covers the engine, not market data.

So you bring LEAN, and Cat Studio never pretends to be the thing doing the computing.

Does it place real trades?

No. Backtests on historical data. The Live button exists because LEAN has one, and it is switched off.

Do all 26 levels work?

Twenty-three. Levels 17, 18 and 19 ask what a company is worth, which needs QuantConnect's paid fine feed. They say so on their own card rather than failing quietly.

Which computers?

Windows 10 and 11. The app is Python with a web UI in a native window.
